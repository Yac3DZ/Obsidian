# Welcome to NoteVault

Your notes are plain Markdown files in a folder on this device.

## Basics
- Create notes with the **+** button (or `Ctrl+N` on Windows)
- Link notes with double brackets, like [[Ideas]] — tap a link to open or create it
- Toggle edit / preview with the eye button (or `Ctrl+E`)
- Use the toolbar for **bold**, *italic*, ==highlight==, ~~strike~~ and more

## Tasks
- [x] Install NoteVault
- [ ] Tap a checkbox in preview to tick it off

## Tips
- Insert images with the image button — they are stored in `attachments/`
- Tag notes with #ideas and tap a tag to find every note that uses it
- `Ctrl+O` opens the quick switcher, the calendar button opens today's daily note
